# Cognifyz Technologies — Data Visualization Internship (Using Microsoft Excel)

## About
This repository contains all 6 tasks completed as part of the **Data Visualization Internship** at **Cognifyz Technologies**, a company specializing in data science, AI, and analytics solutions.

**Duration:** 23 Sept 2026 – 23 Oct 2026
**Dataset:** Investment behavior survey data (40 respondents) — gender, age, investment avenues, reasons for investment, savings objectives, information sources, investment duration, and return expectations.

## Tasks Completed

| Task | Description | Key Tools Used |
|---|---|---|
| Task 1 | Gender Distribution Analysis | PivotTable, Pie Chart |
| Task 2 | Investment Preferences Analysis | PivotTable, Bar Chart, Stacked Bar Chart |
| Task 3 | Objective and Source Analysis | PivotTable, Donut Chart, Horizontal Bar Chart |
| Task 4 | Duration and Expectations Analysis | PivotTable, Histogram, Radar Chart |
| Task 5 | Correlation Analysis | CORREL formula, Scatter Plot Matrix, Bubble Chart |
| Task 6 | Interactive Dashboard | Combined all visualizations, linked Slicers, PivotCharts |

## Skills Demonstrated
- PivotTables and PivotCharts
- Data cleaning and formula-based categorization
- Multiple chart types: Pie, Bar, Donut, Histogram, Radar, Scatter, Bubble
- Interactive dashboard design with linked Slicers (Report Connections)
- Correlation analysis using Excel's CORREL function

## Files
Each task is saved as a separate Excel file (`.xlsx`), containing the underlying dataset, PivotTable(s), and corresponding chart(s).
